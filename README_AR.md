# موقع رَفْد

هذا هو سورس كود النسخة المنشورة من موقع رَفْد:

https://rafd-platform.fatimaalhadadeveneko.chatgpt.site

## أهم الملفات

- `app/page.tsx`: محتوى الموقع والواجهات التفاعلية ومنطق التنبؤ التجريبي.
- `app/globals.css`: التصميم الكامل والألوان المارونية والاستجابة للجوال.
- `app/layout.tsx`: عنوان الموقع وبيانات المشاركة والشعار.
- `public/rafd/`: شعار رَفْد وصور الموقع.

## التشغيل محلياً

يتطلب Node.js 22.13 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح الرابط المحلي الذي يظهر في نافذة الأوامر.

## إنشاء نسخة إنتاجية

```bash
npm run build
```

ملاحظة: منطق التنبؤ الحالي تجريبي داخل `app/page.tsx`. ويمكن لاحقاً استبداله بواجهة API متصلة بنموذج تعلم آلي فعلي وبيانات POS وPMS والطقس.
